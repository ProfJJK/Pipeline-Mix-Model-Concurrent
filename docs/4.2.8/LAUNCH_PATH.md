## The single owner sitting

Deliver one new pinned entry point with a readable launch sheet. Do not chain the
owner through spent R6/R7 commands. Perform the full prerequisite check before
changing the running installation. Reuse the already verified eighteen sessions;
if an actual new login is required, use the approved fresh-URL/Windows-dialog
flow during the first twenty minutes of active input. Gather every necessary
choice then, with no planned late prompt, reboot or continuation command.

After input is complete, the reviewed script performs its bounded installation,
native acceptance and cutover unattended. Total elapsed time may exceed twenty
minutes. A late failure preserves sanitized status and private evidence and uses
the reviewed recovery boundary; it never requests unattended input or guesses
that a model passed because it was unavailable.
