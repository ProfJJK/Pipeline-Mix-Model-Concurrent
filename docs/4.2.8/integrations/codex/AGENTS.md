For requested CoChem submissions, status or completion checks, use the
`codex-pipeline` skill and `cochem-pipeline` MCP server. Check live health and
projects, select the supported intake, submit once and retain the returned ID.
Verify terminal receipts and the requested deliverables.

Direct local pipeline maintenance is exempt. Unrelated local work and exam,
YouTube and Antigravity specialists' workflows remain outside this rule. Do not
redirect those workflows or modify their configuration.

Use the intended repository's configured project or the supported scoped
preparation API. Never substitute the acceptance fixture or a Google Drive
working copy. Preserve sign-ins, quota/backoff, repair budgets and host rules.
Do not launch providers, mutate protected runtime state or restart services to
work around a submission problem. Distinguish verified content, executed tests
and actual Git integration. Refreshed settings are not proof that a current
chat has loaded an unavailable tool.
